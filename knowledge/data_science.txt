# Data Science & Analytics Resume Evaluation Guidance
# Use this to evaluate and provide feedback on data science resumes.

## Key Resume Strengths to Look For
- End-to-end data science project examples (from data collection to deployment)
- Quantified business impact (e.g., "ML model increased conversion by 15%", "Saved $500K/year through churn prediction")
- Published work: papers, blog posts, Kaggle rankings, GitHub repositories
- A/B testing and experiment design experience
- Production model deployment and monitoring (MLOps)
- Domain expertise combined with technical skills

## Metrics That Impress Data Science Leads
- Model performance improvements (accuracy, F1, AUC-ROC)
- Business metrics improved (revenue, retention, cost reduction)
- Data pipeline throughput and efficiency
- Time from experiment to production (model velocity)
- Number of models in production
- Stakeholder impact and cross-team collaboration examples

## Key Areas to Evaluate
### Technical Skills Depth
- Python (pandas, numpy, scikit-learn, TensorFlow/PyTorch)
- SQL proficiency (complex queries, window functions, query optimization)
- Cloud ML services (SageMaker, Vertex AI, Azure ML)
- MLOps: Docker, MLflow, Kubeflow, CI/CD for models
- Visualization: Tableau, Power BI, Looker, matplotlib

### Statistical Knowledge
- Hypothesis testing and statistical significance
- Experimental design and causal inference
- Time series analysis and forecasting
- Bayesian methods and uncertainty quantification
- Feature engineering and selection approaches

### Communication & Impact
- Ability to translate technical findings to business stakeholders
- Data storytelling and visualization clarity
- Documentation and reproducibility practices
- Presentation and report writing skills

## Common Resume Mistakes in Data Science
- Only showing Jupyter notebooks, no production experience
- No GitHub portfolio or project links
- Vague about impact — "built a model" without saying what it achieved
- Too much emphasis on Kaggle competitions, not enough on real-world problems
- Missing SQL proficiency (critical for most roles)
- No mention of data quality challenges or how they were handled
- Overstating model complexity without understanding trade-offs

## Resume Structure Recommendations
1. Professional Summary (domain expertise, key technical skills, impact examples)
2. Technical Skills (Languages, ML Libraries, Cloud, Data Tools)
3. Professional Experience (business problem → approach → result format)
4. Projects & Publications (GitHub links, papers, blog posts)
5. Education (degree, relevant coursework)
6. Certifications (AWS ML, TensorFlow, Coursera specializations)
7. Additional: Kaggle rankings, conference talks, open source contributions
