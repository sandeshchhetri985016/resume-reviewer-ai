# Cyber Security Resume Evaluation Guidance
# Use this to evaluate and provide feedback on cybersecurity resumes.

## Key Resume Strengths to Look For
- Industry certifications (CISSP, CEH, OSCP, Security+, CISA, CISM)
- Incident response experience with specific outcomes (e.g., "Led response to ransomware attack, restored 200 systems in 48hrs")
- Security framework knowledge (NIST, ISO 27001, SOC2, Essential Eight)
- Vulnerability management metrics (e.g., "Reduced mean time to patch from 45 to 7 days")
- Red team / penetration testing experience with findings documented
- Compliance and audit experience with regulatory bodies

## Metrics That Impress Security Leaders
- Incidents detected and response times (MTTD, MTTR)
- Vulnerabilities remediated and risk reduction scores
- Security awareness training completion rates
- Phishing simulation improvement percentages
- Cost savings from security improvements (e.g., "Reduced breach insurance premium by 30%")
- Compliance audit scores or certification achievements

## Key Areas to Evaluate
### Technical Skills
- Network security: firewalls, IDS/IPS, VPNs, segmentation
- Cloud security: AWS Security Hub, Azure Defender, GCP Security Command Center
- Application security: SAST, DAST, penetration testing, code review
- Identity & Access Management: Active Directory, SSO, MFA, PAM
- Security monitoring: SIEM (Splunk, Sentinel, QRadar), SOAR, threat intelligence

### Governance & Compliance
- Policy development and enforcement
- Risk assessment methodologies (ISO 31000, FAIR)
- Business continuity and disaster recovery planning
- Third-party vendor risk management
- Data privacy (GDPR, CCPA, Privacy Act)

## Common Resume Mistakes in Cybersecurity
- Certifications listed without demonstrating application
- No specific security incidents or outcomes described
- Vague about tools — "used SIEM" without naming which one
- Missing the "so what" — what was the business impact of security work?
- Focusing only on technical skills without governance or communication
- No mention of security frameworks or standards worked with

## Resume Structure Recommendations
1. Professional Summary (years in security, specialisation, certs)
2. Technical Skills (Domain, Tools, Frameworks)
3. Certifications (with dates and cert numbers)
4. Professional Experience (incident response, projects, outcomes)
5. Education (degree, relevant coursework)
6. Additional: CTF participations, conference talks, security research
