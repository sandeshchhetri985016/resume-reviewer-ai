# Mobile Development Resume Evaluation Guidance
# Use this to evaluate and provide feedback on mobile development resumes.

## Key Resume Strengths to Look For
- Published apps on App Store/Google Play with download and rating stats
- Cross-platform vs native experience (React Native, Flutter, Swift, Kotlin)
- Performance optimization metrics (e.g., "Reduced app launch time by 60%", "Cut crash rate from 2% to 0.1%")
- CI/CD for mobile (Bitrise, Fastlane, TestFlight, Play Console)
- Architecture patterns (MVVM, Clean Architecture, BLoC, Redux)
- API integration and offline-first architecture experience

## Metrics That Impress Mobile Leads
- App store ratings and user review improvements
- Crash-free session rates (e.g., "Maintained 99.8% crash-free rate")
- App size reductions and load time improvements
- Feature adoption and user engagement metrics
- Build and deployment frequency improvements
- Test coverage and automation percentages

## Key Areas to Evaluate
### Platform Skills
- iOS: Swift, SwiftUI, UIKit, Core Data, Combine
- Android: Kotlin, Jetpack Compose, Android Architecture Components
- Cross-platform: Flutter (Dart), React Native (JavaScript/TypeScript)
- Testing: XCTest, Espresso, Detox, Appium

### Mobile-Specific Concerns
- Push notifications (APNs, FCM)
- Offline storage and sync strategies
- Deep linking and universal links
- Biometric authentication (FaceID, fingerprint)
- Background processing and battery optimization
- App store submission and review process

### Architecture & Engineering
- State management (Redux, Provider, Bloc, Riverpod)
- Dependency injection (Dagger, Hilt, Koin, Swinject)
- Networking layer (Retrofit, Alamofire, URLSession)
- Local storage (Core Data, Room, SQLite, SharedPreferences)

## Common Resume Mistakes in Mobile Development
- No links to published apps or GitHub
- Missing platform-specific knowledge (iOS HIG, Material Design)
- No mention of app store submission experience
- Performance or crash metrics absent
- Only lists frameworks without architecture understanding
- No mention of testing strategy for mobile-specific scenarios

## Resume Structure Recommendations
1. Technical Summary (platforms, key apps, years experience)
2. Technical Skills (Languages, Frameworks, Tools, Platforms)
3. Professional Experience (apps built, metrics, team collaboration)
4. Published Apps (links, download stats, ratings)
5. Open Source / Side Projects (GitHub links)
6. Education (degree, relevant coursework)
7. Additional: Conference talks, blog posts, community contributions
